# 📊 Superstore Data Analytics Project

## 🚀 Project Overview

This is an End-to-End Data Analytics Project built using Python, SQL, and Power BI.

The main objective of this project is to analyze Superstore sales data, extract business insights, and create an interactive dashboard for decision-making.

---

# 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- SQL (MySQL)
- Power BI
- Jupyter Notebook

---

# 📂 Dataset

Superstore Sales Dataset containing:

- Orders
- Sales
- Profit
- Customers
- Products
- Regions
- Shipping Details

---

# 📌 Project Workflow

## 1️⃣ Data Collection
- Imported CSV dataset using Pandas

## 2️⃣ Data Cleaning
- Checked missing values
- Removed inconsistencies
- Converted data types
- Fixed date columns

## 3️⃣ Exploratory Data Analysis (EDA)
- Sales Analysis
- Profit Analysis
- Category-wise Analysis
- Region-wise Analysis
- Monthly Sales Trends

## 4️⃣ SQL Analysis
Performed business queries using MySQL:

- Total Sales
- Top Customers
- Monthly Revenue
- Best Selling Products
- Profit Analysis
- Regional Performance

## 5️⃣ Dashboard Creation
Created an interactive Power BI dashboard with:

- KPI Cards
- Sales Trends
- Profit Insights
- Regional Analysis
- Product Performance

---

# 📊 Key Insights

- Technology category generated the highest sales
- Some products had high sales but low profit
- Western region performed best overall
- Monthly trends revealed seasonal demand patterns
